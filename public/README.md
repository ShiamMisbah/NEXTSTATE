# Upload Your Custom Hero Video Here

To use your custom uploaded video file in the hero section of the homepage:

1. Drag and drop or upload your video file directly into this `public` folder in the code editor.
2. Make sure it is named exactly one of the following:
   - `Dhaka_Elevated_Expressway_(Aero).webm`
   - `Dhaka_Elevated_Expressway_(Aero).mp4`
   - `hero_video.webm`
   - `hero_video.mp4`

If any of these files are present, the application will automatically play it instead of the default fallback video of Bangladesh!
